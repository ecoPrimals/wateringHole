## The Backscatter Pattern

Work flows outward: mesh → membrane → hub → HUD → human.
Evidence flows inward: human → HUD → hub → membrane → mesh.

The **backscatter** is the return signal. When the HUD sees a human,
the membrane classifies them, the hub records the evidence, and the
wateringHole tracks the evolution. The wateringHole is where the
organism learns from its own operation.

```
Human visits hud.primals.eco
  → membrane sorts (epitope, braid, passage)
  → squirrel observes (campfire story)
  → neutron records (notes, journal)
  → wateringHole fossils (permanent record)
  → sporePrint cites (evidence page)
  → HUD tells the story (chipmunk, oral tradition)
  → Human reads the story about themselves being read
  → Klein fold complete
```
