# ecoPrimals Documentation

Sovereign distributed scientific computing in Pure Rust. No CUDA. No cloud. No vendor lock-in.

## Guides

- **[Getting Started with Sovereign Scientific Computing](getting-started.md)** — Setup, architecture overview, hardware requirements, and first steps.

- **[WebGPU vs CUDA for Scientific Computing](webgpu-vs-cuda.md)** — Why we chose WebGPU/WGSL over CUDA for lattice QCD, molecular dynamics, and protein structure prediction. Includes performance benchmarks and cost analysis.

- **[Protein Structure Prediction in Pure Rust](protein-structure-rust.md)** — helixVision: a sovereign AlphaFold alternative. Runs on AMD, Intel, NVIDIA GPUs — even a Steam Deck.
